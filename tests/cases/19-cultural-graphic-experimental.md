# 场景 19：文化图形与实验视觉

## 输入

“我要做文化图形实验，不需要规整满铺；希望高密度、强对比、带扫描与错位质感，但文化来源还在核实。”

## 预期路由

进入纹样设计专项中的“独立文化图形/实验视觉”分支，不强制二方连续或四方连续；阶段判定为“概念深化”。

## 必须行为

- 明确对象分类不是重复纹样或 IP 角色。
- 用证据占位、概念假设和禁止推断保护真实性。
- 给出高密度信息层级、实验图形规则、线条精度、颜色层级和版面比例。
- 若加入重复模块，仅作为辅助图形并说明边界，不伪装为无缝纹样。

## 禁止行为

- 不得虚构文化寓意、工艺步骤、展览或获奖事实。
- 不得为了“传统感”擅加无依据符号。
