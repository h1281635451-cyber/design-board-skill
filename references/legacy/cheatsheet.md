# 速查表

## 决策规则

- 中文文案多、或已经出过乱码 → **降到效果版**，图占比拉到 ≥85%，标注压到 1–2 字。因为 AI 写中文最容易崩，字越少越稳。
- 竞赛 / 作品集要高级感 → **升高级版**，先写准 `[统一基底参数]` 八要素，再逐张只写布局 + 内容。
- 课程作业要展示推导过程 → **基础版**，接受一定崩坏率，用信息量换。
- 有参考图 → 写「100% 参考提供的 XX 的排版风格与高级质感」，**优先于任何风格形容词**。
- ≥3 张系列 → 一律抽基底参数。发现自己在每张重抄同一句视觉描述，就是该抽的信号。
- 第 2…N 张 → 开头必须有系列延续句，「统一」与「不重复」同时写。只写统一得到 N 张一样的图，只写不重复得到 N 个项目。
- 主色 → 必须带 hex 或 RGB 数值。只写「朱砂红」，五张会得到五种红。
- 一次出 5 张竞赛版失败成本高 → 第 5 张（整版 Hero Image）单独出。
- VIS 手册 20 页 → 分 4 批，每批 5 页，每批重述 `[通用前缀]`。

## 布局词选择

| 这张要表达 | 用这个布局词 |
|---|---|
| 主体 + 说明并列（首张） | 非对称左右分割布局 |
| 大图在上、信息在下（首张） | 非对称上下分割布局 |
| 系统 / 规范（色卡、字体、制图） | 3×3 不规则打破对齐网格排版 |
| 拆解 / 分析（爆炸图、材质、灯光） | 2×3 不规则打破对齐网格排版 |
| 辅助图形 / 图案系统 | 满版视觉主导排版 |
| 衍生品 / 文创应用 | 无分割线全景式拼贴排版 |
| 实景落地（系列收尾） | UE5 超写实 3D 渲染，全屏大图主导排版 |

五张不重复。每张都要写明版面占比，禁用「适当 / 合理」。

## 叙事节奏

- 五张竞赛版：`概念 → 角色 → 产品创新 → 品牌落地 → 真实生活`
- 三张课程作业版：`概念总览 → 系统 / 规范 → 落地应用`
- 系列越往后文字越少：首张可有一句设计理念，末张「无任何说明文字」。这是降崩坏率的设计。

## 阈值与默认值

| 项 | 数值 |
|---|---|
| 效果版图占比 | ≥85% |
| 高级版图占比 | 75%–95% |
| 中部主视觉高度 | 占版面 1/3 |
| 封面 / 封底留白 | 95% |
| 底部信息栏 | 10% |
| 底部全留白 | 5% |
| 极简标注 | 1–2 字 |
| 左上角说明 | 仅 2 行 |
| 一句话设计理念 | ≤15 字 |
| 禁止项条数 | 12–20 条 |
| 角色比例公式 | 30% 识别特征 + 70% 人格化 |
| Q 版比例 | 三头身以下 |
| 主力规格 | A3 竖版 ≈297:420 |
| 竖版备选 | 2:3，2048×3072 |

## 四个必须点名的槽位

写主视觉系统时逐槽检查，任何一个空着都会掉回默认廉价感：

1. **材质** — 点到具体材料名（哑光树脂 / ABS / 软胶 / 硅胶 / 金属小结构 / 微水泥 / 宣纸纹理 / 青田石 / 黄铜）。禁写「高级材质」。
2. **配色** — 三层：留白底色（白 / 暖白 / 浅灰 / 米白）→ 低饱和情绪色 → 小面积点缀（朱砂红 / 青瓷绿 / 乌漆黑 / 琥珀黄）。主色带数值。
3. **字体** — 中英刻意拉开反差。现代线：无衬线 + Helvetica / Neue Haas Grotesk / Akzidenz Grotesk 气质。国风衣：书法体 + 朱红飞白 + 朱砂印章 + 宋体。
4. **光影** — 写清方向（暖色自然日光 / 柔和侧逆光 / 暖柔侧光形成柔和阴影 / 柔和接触阴影）+ 景深（浅景深 / 高级电影级景深 / 45 度俯视）。

质量闸门一句话：**「使产品看起来像已经生产出来、可以真实销售的高端实体文创潮玩。」**

## 禁止项三层（一层都不能漏）

- **反套路层**（按题材现写）— 做生肖：不要龙纹、祥云纹、剪纸、红金配色。做国风：不要祥云、纹样、书法、宫廷元素堆砌。
- **反廉价层** — 不要学生作业感 / 廉价潮玩风 / 廉价电商详情页样式 / 艳丽渐变背景 / 霓虹色 / 过强饱和度 / 赛博朋克 / 塑料材质 / 夸张五官。
- **反崩坏层** — 不要乱码 / 水印 / 展板编号（01 02 03）/ 任何奖项 LOGO（Red Dot / iF / IDEA）/ 拼版九宫格 / 多张小图并排 / 作者姓名导师致谢 / 人物变形 / 产品重复 / 结构错误。

## 症状 → 病因

| 看到 | 病因 | 改法 |
|---|---|---|
| 中文字乱码 / 伪文字 | 字太多 | 降效果版，图占比 ≥85%，标注 1–2 字 |
| 角色每张长得不一样 | 没有属性枚举 | 锁定句补「造型、配色、材质、五官、比例高度一致」 |
| 五张像五个项目 | 缺系列延续句的「统一」半句 | 第 2…N 张开头补延续句 |
| 五张几乎一样 | 缺「不与第一张重复」 | 延续句补后半句 + 整套换新模块清单 |
| 五张的红色不同 | 主色没带数值 | 补 hex / RGB |
| 得到一张九宫格 | 缺独立输出声明 | 补「N 张独立图片，不要拼版 / 九宫格 / 编号」 |
| 版面像电商详情页 | 禁止项漏了反廉价层 | 补「拒绝廉价电商详情页样式」「不要学生作业感」 |
| 做生肖出了龙纹红金 | 禁止项漏了反套路层 | 按题材现写反套路层 |
| 出了奖项 LOGO / 页码 | 禁止项漏了反崩坏层 | 补「不要任何奖项 LOGO」「不要出现展板编号」 |
| 只出第 1 张就停 | 缺一次性完成声明 | 补「请一次性完成全部 N 张，不要只生成第 1 张就结束」 |
| 出现作者 / 导师 / 学校信息 | 基底参数漏第 8 要素 | 补「无作者姓名、指导教师、致谢等无关文字」 |

## 出图后七条门禁

1. N 张是否都真的输出了
2. 中文全部可读、无乱码伪文字错别字
3. 角色 / LOGO / 主体造型配色比例跨张一致
4. 无奖项 LOGO、页码、水印、作者导师学校信息
5. 未被拼成长图 / 九宫格 / 多图并排
6. 图占比达标、留白充足
7. 整体像同一个设计师做的完整系列

任何一条不过就改提示词重出，不要靠后期修。
