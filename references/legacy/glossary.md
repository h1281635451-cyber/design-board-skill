# 术语表

按拼音 / 字母排序。括号内为出处章节。

## 符号与拉丁词头

**2×2 模块化分区** — 展板下方四个等大模块的标准布局，每格一个中英双标题模块（Ch3）
**2:3 竖版** — 建议 2048×3072 像素的竖版比例，用于文创产品展板（Ch3）
**30/70 比例公式** — 「30% 生肖识别特征 + 70% 人格化状态造型」，角色设定的量化写法（Ch4）
**8K 高清无水印** — 基底参数第 7 要素，清晰度与水印排除的固定写法（Ch2）
**A1 竖版** — 大幅竞赛展板规格（Ch3）
**A3 竖版** — 主力规格，约 297:420，全文出现 87 次（Ch3）
**C4D / Octane / Blender** — 高端产品渲染管线锚点词（Ch4）
**CMF** — Color-Material-Finish，色彩材质工艺展示模块（Ch4）
**RCA / UAL** — 皇家艺术学院 / 伦敦艺术学院，用作排版气质的参照锚点（Ch2）
**UE5 超写实渲染** — 实景落地页的渲染锚点词（Ch3）

## B–F

**爆炸图** — 产品结构分层拆解图，产品设计展板的必备模块（Ch3）
**布局词** — 声明版式类型的短语，如「3×3 不规则打破对齐网格排版」；每张换一个，五张不重复（Ch3）
**参考图锚定** — 「100% 参考提供的 XX 展板的排版风格与高级质感」，有参考图时优先于任何形容词（Ch3）
**独立输出声明** — 「N 张独立图片，不要拼版 / 九宫格 / 多张小图并排 / 展板编号」（Ch1）
**反差主张** — 项目核心概念的一句话断言，如「生肖不是身份，是状态」（Ch1）
**附着逻辑 / 摆放逻辑** — 「把玩具从摆放逻辑变成附着逻辑」，用「从 X 逻辑变成 Y 逻辑」句式说清产品创新（Ch4）

## G–M

**高级版** — 三档中的最高档，`[统一基底参数]` + 实验性版式词汇 + 占位符驱动（Ch2）
**极简标注** — 「仅在最大的 3 个核心图形旁标注 1-2 字极简说明」，效果版不崩坏的关键（Ch3）
**禁止项三层** — 反套路层 / 反廉价层 / 反崩坏层，写禁止项时逐层检查（Ch4）
**冷静脸 + 夸张动作** — 「两个点眼睛 + 一条平直嘴」配戏剧化身体动作，通过反差形成 IP 识别（Ch4）
**留白** — 版面空白比例，常写到具体数值：「整版 95% 留白」（Ch3）
**满版视觉主导排版** — 布局词之一，用于辅助图形 / 图案系统页（Ch3）
**模块声明格式** — 「▢ 模块N：中文名 | English Name」+ 下一行「内容：…」的两行格式（Ch3）

## P–S

**平庸版 / 冲击力强** — 信息可视化模板刻意成对保留的两种气质档位，按评审口味挑（Ch2）
**三档递进** — 基础版 → 效果版 → 高级版，差别在中文字密度而非内容多少（Ch2）
**属性枚举** — 一致性锁定必须落到可核对属性：造型、配色、材质、五官、比例（Ch1）
**视觉节奏五段** — 概念 → 角色 → 产品创新 → 品牌落地 → 真实生活（Ch3）
**四词交叉定位** — 用 × 连接四个不相关定位词，如「东方 × 荒诞 × 当代设计玩具 × 高端工业设计」（Ch4）

## T–Z

**通栏** — 横向贯穿整版的区块，如「顶部通栏大标题」「底部极窄通栏」（Ch3）
**[通用前缀]** — VIS 手册 20 页的基底参数标记，每页开头复述一次（Ch2）
**[统一基底参数]** — 高级版的核心机制，跨张不变的八要素视觉参数抽成一段（Ch2）
**图占比** — 图像在版面中的占比，效果版要求 ≥85%（Ch3）
**网格排版** — 「3×3 / 2×3 不规则打破对齐网格排版」，用于系统规范页与拆解页（Ch3）
**系列延续句** — 第 2…N 张开头的一致性复述，必须同时含「统一」与「不重复」（Ch2）
**效果版（字少不容易崩坏）** — 三档中的默认起点，图占比 ≥85%、标注压到 1–2 字（Ch2）
**已量产判据** — 「使产品看起来像已经生产出来、可以真实销售的高端实体文创潮玩」（Ch4）
**一致性锁定句** — 提示词第一句，声明 N 张属同一项目 / 视觉系统 / IP 角色（Ch1）
**羽化处理** — 「图片边缘做微渐变羽化处理融入底色」，让大图与底色衔接（Ch3）
**占位符** — 模板待填项，统一用 `（圆括号）` 或 `[方括号]`；只替换内容不改句式（Ch2）
**主视觉** — 一张展板的视觉中心，中部主视觉通常占版面 1/3 高度（Ch3）
**逐张规格** — 六段架构第 4 段，每张一个独立段落：布局词 + 版面占比 + 模块清单 + 独有内容（Ch1）
