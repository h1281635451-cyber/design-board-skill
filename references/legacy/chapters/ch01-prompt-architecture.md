# 第 1 章：六段提示词架构

## Core Idea

一套能稳定出图的展板提示词，本质是**把「跨张不变」和「每张独有」彻底分开**：前六段里的 1、2、3、5、6 段全是跨张不变的锁定，只有第 4 段（逐张规格）允许变化。写反了这个顺序——先描述画面再补一致性要求——AI 就会把一致性当成可选项。

## Frameworks Introduced

- **六段架构（Six-Block Prompt Architecture）**：一致性锁定 → 项目设定 → 主视觉系统 → 逐张规格 → 全局统一要求 → 禁止项。
  - 何时用：任何需要一次生成 ≥2 张视觉统一图的场合。
  - 怎么做：严格按此顺序成文，每段独立成块，不要在段间穿插。
  - 为什么有效：图像模型对提示词头部权重最高。把一致性声明放第一句，它就成了约束条件；放到最后，它就成了建议。

- **反差主张（Contrast Thesis）**：项目核心概念必须是一句带张力的断言，不是描述。
  - 源文档原例：「**生肖不是身份，是状态。**」「这不是一个普通『摆在桌面上』的潮玩。它的核心不是『摆』。而是：**它什么都要抱。**」
  - 何时用：写第 2 段项目设定时。
  - 判据：这句话能不能直接印在展板上当标语。不能，就还没想清楚。

- **负面清单前置化**：`不要…` 在源文档里出现 125 次，是最高频的句式，远超任何正面描述。
  - 关键写法是**成组连续否定**，一条一行，不合并成一句：
    > 不要传统国潮。／不要龙纹、祥云纹、剪纸、红金配色等传统生肖视觉套路。／不要普通可爱萌宠。／不要廉价潮玩风。／不要学生作业感。
  - 为什么有效：正面描述告诉模型「往哪走」，否定告诉模型「哪条路已经堵死」。设计类的廉价感是模型的默认输出，不显式排除就一定会出现。

## Key Concepts

- **一致性锁定句**：开头那句「必须属于同一个设计项目、同一套视觉系统、同一套 IP 角色」，后面紧跟需要锁定的属性枚举（造型、配色、材质、五官、比例）。
- **属性枚举**：锁定必须落到可核对的属性上。「风格统一」不可核对，「造型、配色、材质、五官、比例高度一致」可核对。
- **逐张规格**：每张一个独立段落，含布局词 + 版面占比 + 模块清单 + 该张独有内容。
- **全局统一要求**：跨张的网格、留白、对齐、边框、光影声明，通常紧跟一句「五张需要像同一个设计团队完成的完整国际竞赛作品」。
- **禁止项**：收尾清单，覆盖奖项 LOGO / 页码编号 / 水印 / 乱码 / 拼版九宫格 / 作者导师学校信息。
- **输出形态声明**：「请一次性输出 N 张**独立的** A3 竖版图片，不是把五张内容放在同一张图片里」——这句必须显式写，否则默认会拼版。

## Mental Models

把提示词当成**给外包设计师的任务书**，而不是许愿。任务书里没写的约束，外包会自己发挥；AI 也一样。

用「不变量 / 变量」看整套提示词：不变量写进基底参数和全局段，变量才进逐张段。当你发现自己在每张里重复同一句视觉描述，那就是该抽成 `[统一基底参数]` 的信号（见第 2 章）。

## Anti-patterns

- **只写正面描述**：满篇「高级、精致、极简」，没有一条 `不要`。结果一定是廉价渐变 + 电商详情页感。
- **一致性要求放在结尾**：模型已经生成完画面才读到约束，等于没写。
- **属性锁定写成形容词**：「风格要统一」不可执行；必须枚举到造型 / 配色 / 材质 / 五官 / 比例这一层。
- **忘记声明独立输出**：得到一张九宫格拼图，五张内容挤在一起，无法单独使用。
- **核心概念写成说明文**：「本项目旨在探索传统文化与现代设计的结合」——这句话不产生任何视觉决策。

## Worked Example

源文档「今天属什么？」的开头三段，逐字展示了架构前三段如何落地：

> **（第 1 段 一致性锁定）** 请一次性为我生成 **5 张完整的 A3 竖版产品设计竞赛展板**，五张必须属于同一个设计项目、同一套视觉系统、同一套十二生肖 IP 角色，角色造型、配色、材质、五官、比例在五张展板中必须高度一致。
>
> **（第 2 段 项目设定 + 反差主张）** 项目名称：今天属什么？／WHAT ARE YOU TODAY?／TWELVE ZODIAC MOODS。项目核心概念：**生肖不是身份，是状态。** 传统生肖由出生年份决定，但人的状态每天都会变化。因此，将传统十二生肖重新设计为十二种当代年轻人的人格与情绪状态：藏 / 扛 / 冲 / 逃 / 飘 / 绕 / 跑 / 贴 / 搞 / 醒 / 等 / 躺。不是「一辈子只能属一个」，而是「一天可以换好几个」。
>
> **（第 3 段 主视觉系统，节选）** 整体视觉方向：**东方 × 荒诞 × 当代设计玩具 × 高端工业设计**。不要传统国潮。……核心气质：极简 / 克制 / 大面积留白 / 图多字少 / 产品视觉优先 / 精致 3D 产品渲染 / 高级编辑设计 / 清晰的信息层级 / 有趣但不幼稚 / 创新但必须可以真实落地。字体使用现代无衬线风格……主要背景以白色、暖白、浅灰、米白为主。允许十二个角色使用不同的低饱和情绪色。

注意第 3 段的写法：先给一个**四词交叉定位**（东方 × 荒诞 × 当代设计玩具 × 高端工业设计），紧跟五条连续否定把默认套路堵死，再给一串可执行的气质词。这个「定位 → 否定 → 枚举」三连是整个库的通用节奏。

## Key Takeaways

1. 六段顺序是硬约束：一致性锁定必须第一句，禁止项必须收尾。
2. 锁定要枚举到可核对的属性（造型 / 配色 / 材质 / 五官 / 比例），形容词不算锁定。
3. `不要…` 成组连写、一条一行，是控制廉价感最有效的手段。
4. 项目核心概念写成一句能印上展板的反差主张。
5. 显式声明「N 张独立图片，不要拼版 / 九宫格 / 编号」。
6. 写新提示词前先判断：这句话是跨张不变量还是单张变量？不变量不属于逐张段。
