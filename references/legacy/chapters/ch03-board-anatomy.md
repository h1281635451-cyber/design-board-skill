# 第 3 章：单张展板骨架与叙事节奏

## Core Idea

每张展板都是同一个三段式骨架：**顶部通栏大标题 → 中部主视觉 → 下方模块化分区**。变的只是布局词、版面占比和模块内容。骨架固定下来，AI 才不会每张都重新发明一种版式。

## Frameworks Introduced

- **固定三段骨架（Fixed Three-Band Skeleton）**：源文档效果版模板的原话——「严格采用『顶部通栏大标题 + 中部主视觉群像 + 下方 2×2 模块化分区』的固定结构，所有元素对齐规整，无多余装饰。」
  - 何时用：所有课程作业 / 作品集展板（效果版、基础版）。
  - 三段的高度分配：中部主视觉**占版面 1/3 高度**，下方模块区占其余，顶部通栏最窄。
  - 关键约束：写完骨架声明后紧跟「必须包含以下固定模块，内容全部填充对应括号内信息」，然后用编号列出模块。

- **模块声明格式**：每个模块两行，中英双标题 + 内容说明：
  ```
  ▢ 模块1：核心主形象 | Core Image
    内容：IP标准正面全身超清3D渲染图
  ▢ 模块2：盲盒系列 | Blind Box Series
    内容：5款不同主题盲盒的3D渲染图，成组整齐排列
  ```
  为什么中英并列：英文标题是纯拉丁字符，AI 几乎不会写错，能在中文崩坏时保住版面的专业感。

- **布局词汇表（Layout Vocabulary）**：高级版每张换一个布局词，且**五张不重复**。源文档实际用到的七种：
  | 布局词 | 适用张次 / 意图 |
  |---|---|
  | 非对称左右分割布局 | 首张，主体 + 说明并列 |
  | 非对称上下分割布局 | 首张，大图在上信息在下 |
  | 3×3 不规则打破对齐网格排版 | 系统 / 规范页（色卡、字体、制图） |
  | 2×3 不规则打破对齐网格排版 | 拆解 / 分析页（爆炸图、材质、灯光） |
  | 满版视觉主导排版 | 辅助图形 / 图案系统页 |
  | 无分割线全景式拼贴排版 | 衍生品 / 文创应用页 |
  | UE5 超写实 3D 渲染，全屏大图主导排版 | 实景落地页，系列收尾 |

- **版面占比纪律（Proportion Discipline）**：每个区块都写明百分比，从不写「适当」「合理」。源文档实际数值：`上半部分 70% 版面` / `下半部分 30%` / `左侧 1/3 通栏` / `右侧 2/3 区域` / `其余 90% 版面` / `其余 95% 版面` / `图占比 80%` / `图占比 75%` / `图占比≥85%` / `占版面 1/3 高度` / `底部信息栏（占版面 10%）` / `底部全留白（占版面 5%）`。

- **极简标注纪律**：`仅在最大的 3 个核心图形旁标注 1-2 字极简说明`、`所有标注仅用 1-2 字极简说明`、`仅在产品旁标注 1 字极简名称`、`无任何说明文字`。这是效果版不崩坏的关键。

## Key Concepts

- **五张叙事节奏**：`概念 → 角色 → 产品创新 → 品牌落地 → 真实生活`（源文档原话：「视觉节奏从概念 → 角色 → 产品创新 → 品牌落地 → 真实生活逐步推进」）。
- **三张节奏（课程作业版）**：概念总览 → 系统 / 规范 → 落地应用。
- **VIS 20 页节奏**：封面 → 目录 → 品牌理念 → LOGO 标准（横 / 竖 / 符号）→ 色卡 → 字体 → 辅助图形 → 组合规范 → 禁用规范 → 材质实验 → 办公 → 文创 → 包装 → 服饰 → 户外导视 → 数字媒体 → 门头 → 室内 → 封底。
- **输出规格**：A3 竖版（约 297:420，主力，全文 87 次）／A1 竖版（大幅竞赛）／2:3 竖版（建议 2048×3072）／横版 A4（VIS 手册）。
- **独立输出声明**：「只生成一张 A3 竖版独立展板，不要拼版，不要把五张展板放在同一张图里，不要九宫格，不要多张小图并排，不要出现展板编号。」
- **参考图锚定**：`100%参考提供的云南瓦猫IP展板的排版风格与高级质感` / `请以我上传的五张展板图片为核心视觉参考` / `参考图一的排版和格式生成`。有参考图时，这句比任何风格形容词都管用。

## Mental Models

把每张展板想成**一页杂志**，不是一张海报。杂志页有固定的栏格、图注规范和留白节奏；海报只追求单张冲击。库里反复出现的「像成熟作品集页面，而不是普通宣传海报」「拒绝廉价电商详情页样式」就是这个区分。

布局词是**版式的类型标注**：先声明类型（网格 / 满版 / 拼贴 / 全屏大图），再填内容。不声明类型，AI 会默认给你居中大字海报。

## Anti-patterns

- **五张用同一个布局词**：源文档明确要求「避免五张展板构图完全重复，每张必须有独立信息重点，但整体视觉风格必须高度一致」。
- **占比写「适当」「合理」**：不可执行，等于没写。
- **模块只有中文名**：中文一崩整块就废，加英文副标题能保住版面。
- **每张都想塞满信息**：系列越往后应该越依赖视觉。
- **忘记独立输出声明**：拿到一张九宫格。

## Worked Example

「IP 展板（效果版）」三张的完整骨架（L1817–1875），是固定三段骨架 + 模块声明格式最干净的样例：

> **展板 1** 生成竖版 A3 尺寸的高校设计作业 IP 展板，100% 参考提供的云南瓦猫 IP 展板的排版风格与高级质感，整体为成熟作品集页面，字少图多，以 3D 潮玩视觉效果为绝对核心，文字仅保留核心标题与极简说明，边框整洁，黑白灰底色搭配 IP 主色调点缀，字体统一为无衬线粗体 + 细体英文辅助。
> 严格采用「顶部通栏大标题 + 中部主视觉群像 + 下方 2×2 模块化分区」的固定结构。
> 1. 顶部通栏 —— 大标题：（IP中文名称）IP形象设计／英文副标题：（IP英文名称）Image Design／右上角小字：（核心文化/主题系列）／左上角极简说明（仅2行）
> 2. 中部主视觉（占版面 1/3 高度）—— IP 主形象 + 4 款同系列家族形象（共 5 个）高清 3D 渲染
> 3. 下方四个等大模块（2×2）—— 核心主形象 | Core Image／盲盒系列 | Blind Box Series／细节拆解 | Detail Breakdown／标准色卡 | Color Palette
>
> **展板 2** 与上一张「IP 核心形象总览板」风格 100% 完全统一……严格采用「顶部通栏大标题 + **中部动态主视觉** + 下方 2×2 模块化分区」的固定结构。模块：标准三视图 | Three Views／表情包系列 | Emoji Pack／主题场景 | Theme Scene／造型变体 | Style Variation
>
> **展板 3** 与前两张 IP 设计展板风格 100% 完全统一……全部为落地应用内容。模块：日用文创 | Daily Goods／餐饮周边 | Catering Merch／户外广告 | Outdoor Ads／数字周边 | Digital Products

三张的骨架声明**字面相同**，只有中部主视觉的定语换了（群像 → 动态 → 大型装置），模块清单整套换新。这就是「结构复用 + 内容全新」的标准做法。

## Key Takeaways

1. 每张都用固定三段骨架，并在提示词里显式声明这个骨架。
2. 模块用「中文名 | English Name」双标题 + 内容说明的两行格式。
3. 每张换一个布局词，五张不重复；布局词来自第 3 节的词汇表。
4. 所有区块写明百分比占比，禁用「适当 / 合理」。
5. 标注压到 1–2 字，系列越往后文字越少。
6. 五张按 `概念 → 角色 → 产品创新 → 品牌落地 → 真实生活` 推进。
7. 有参考图就写「100% 参考…的排版风格与高级质感」。
