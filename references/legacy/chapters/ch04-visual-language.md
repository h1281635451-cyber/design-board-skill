# 第 4 章：视觉语言与负面清单系统

## Core Idea

「高级感」在这个库里不是形容词，是一组可复用的具体名词：材质有名有姓、配色带 RGB、字体指名到字族、光影写清方向。而把廉价感挡在门外的，是**分层的负面清单**——库里 `不要` 出现 125 次，是全文最高频句式。

## Frameworks Introduced

- **材质点名法（Named Materials）**：从不写「高级材质」，一律点到具体材料名。
  - 潮玩 / 文创玩具：`哑光树脂`、`ABS`、`软胶`、`硅胶`、`金属小结构`、`细腻哑光树脂彩塑`、`手工陶塑质感`、`精细涂装`、`哑光柔感材质，细腻、柔和、略有亲肤感`
  - 空间 / 室内：`微水泥肌理`、`天然洞石`、`深浅交错的仿木纹雕刻`、`真实木板拼接`
  - 平面 / 国风：`宣纸纹理`、`壁画肌理`、`金石质感`、`青田石 / 黄铜 / 黑檀木 / 冻石`（印章四材质）
  - 水体 / 瓷器：`高品质青花瓷`、`清澈透明水体`、`细腻水纹、真实倒影、波纹折射、环境高光`
  - 何时用：第 3 段主视觉系统，以及每张展板的产品 / 场景描述。

- **配色三层法（Three-Layer Palette）**：
  1. **底色层**——大面积留白：`白色、暖白、浅灰、米白`（源文档：「主要背景以白色、暖白、浅灰、米白为主」）
  2. **情绪色层**——低饱和、允许每个角色 / 模块不同：`允许十二个角色使用不同的低饱和情绪色`
  3. **点缀层**——小面积高识别：`朱砂红 / 青瓷绿 / 乌漆黑 / 琥珀黄`、`米白底色 + 墨黑 + 赭石色点缀`
  - **硬规则：主色必须带 RGB 或 hex 数值。** 源文档实例：`朱红 #C83227`、`石青 #355775`、`暖橙 #E66B35`、`墨黑 #292522`、`月白 #F4EDE3`、`香槟金 #CBA66A`；`主色 1 (RGB: 245,240,235) × 主色 2 (RGB: 68,52,46) 侘寂风经典冷暖撞色`。
  - 为什么：只写「朱砂红」，五张会得到五种红。

- **字体反差法（Type Contrast）**：中文与英文刻意拉开风格差，这本身就是一种设计语言。
  - 现代 / 国际路线：`现代无衬线`、`类似 Helvetica、Neue Haas Grotesk、Akzidenz Grotesk 的现代字体气质`、`中文字粗细对比明确`、`无衬线粗体 + 细体英文辅助`、`中文细黑体 × 英文极细无衬线字体`
  - 国风路线：`极具笔墨张力的黑色中国书法字体，局部笔画融入朱红色飞白与朱砂印章效果` + `典雅的宋体或现代中式衬线字体` + `清晰的中文细宋体`；或 `思源宋体 + 思源黑体`
  - 实验路线：`(中文手写字体风格) × (英文无衬线字体风格) 强烈风格反差`、`软糯圆润手写中文 × 极简纤细无衬线英文`

- **负面清单三层（Three-Layer Negative List）**：源文档所有 `不要…` 实际归为三类，写禁止项时按层检查是否都覆盖到了：
  | 层 | 排除什么 | 源文档原句 |
  |---|---|---|
  | **反套路层** | 文化题材的默认视觉陈词 | 不要传统国潮／不要龙纹、祥云纹、剪纸、红金配色等传统生肖视觉套路／不要做传统中国风／不要祥云、纹样、书法、宫廷元素堆砌 |
  | **反廉价层** | 模型默认的low输出 | 不要普通可爱萌宠／不要廉价潮玩风／不要学生作业感／拒绝廉价电商详情页样式／不要艳丽渐变背景／不要霓虹色、过强饱和度、赛博朋克或廉价卡通效果 |
  | **反崩坏层** | AI 特有的失败模式 | 不要出现乱码／不要水印／不要出现展板编号（01 02 03）／不要任何奖项 LOGO（Red Dot / iF）／不要拼版、九宫格、多张小图并排／不要人物变形、产品重复、机关结构错误／无作者姓名、指导教师、致谢等无关文字 |

- **冷静脸 + 夸张动作（Deadpan Contrast）**：IP 角色的核心识别机制。
  - 源文档原话：「统一使用非常淡定的面部系统：**两个点眼睛 + 一条平直嘴**。动作很荒诞，但脸非常平静，通过这种反差形成 IP 识别。」
  - 抱住猴版本：「两个极小的眼睛，一条极简的嘴线，表情安静甚至略微『冷淡』。但是身体动作非常戏剧化。形成：**冷静的脸 + 夸张的动作** 这种反差感。」

- **比例反差公式**：`30% 生肖识别特征 + 70% 人格化状态造型`；抱住猴的 `小头 / 大耳 / 大手 / 大脚 / 超细腰 / 超长四肢 / 超长尾巴`；小班过江的 `三头身以下的 Q 版比例，头大身小，脸部饱满，鼻子小巧`。
  - 为什么有效：给一个**数字比例**比给一串形容词可控得多。

## Key Concepts

- **光影词库**：`暖色自然日光`、`柔和侧逆光`、`真实环境反射`、`高级电影级景深`、`柔和自然侧光`、`暖柔侧光打在物品上形成柔和阴影`、`柔和接触阴影`、`浅景深`、`45 度俯视视角`。
- **渲染词库**：`C4D`、`Octane 渲染器`、`Blender 高级产品渲染`、`UE5 超写实渲染`、`8K 超清`、`微距商业产品摄影`、`高级商业产品摄影质感`。
- **「已量产」判据**：源文档原话——「必须呈现高级商业产品摄影质感，使产品看起来像**已经生产出来、可以真实销售**的高端实体文创潮玩。」这是检验渲染质量的一句话标准。
- **附着逻辑 vs 摆放逻辑**：抱住猴的产品创新叙事——「把玩具从『摆放逻辑』变成『附着逻辑』。它不需要固定底座，可以直接进入用户真实生活空间。」产品创新点要用这种「从 X 逻辑变成 Y 逻辑」的句式说清。
- **四词交叉定位**：`东方 × 荒诞 × 当代设计玩具 × 高端工业设计`、`江南水乡文化 × 中国民间彩塑 × 戏曲文化 × Q版文创潮玩`。用 × 连接四个不相关的定位词，比单独堆形容词更能产生独特性。

## Mental Models

把材质 / 配色 / 字体 / 光影想成**四个必须点名的槽位**。写主视觉系统时逐槽检查：材质点到具体材料名了吗？配色带数值了吗？字体指名到字族了吗？光影写清方向了吗？四个槽都填满，「高级感」才有落点。

负面清单是**默认输出的补集**。AI 的默认输出是学生作业感的电商海报，所以禁止项不是在挑剔，是在描述「不要落到默认值上」。

## Anti-patterns

- **写「高级材质 / 精致配色 / 优质光影」**：三个槽位全空，等于没写。
- **配色不带数值**：五张五个色。
- **禁止项只写反崩坏层**：漏掉反套路层，做生肖就一定出龙纹祥云和红金配色。
- **用形容词堆角色设定**：不给比例公式（30/70、三头身、小头大手），角色每张都会重新长一遍。
- **国风就默认书法 + 祥云 + 红金**：源文档明确反对——东方表达要「非常克制」，只通过一个抽象元素进入（如尾巴的抽象如意曲线），加一套色彩系统。

## Worked Example

「小班过江」的主视觉系统段（L924–946），四个槽位全部点名的标准写法：

> **统一美术风格** —— 整体采用高端 3D 文创潮玩产品渲染风格，融合 C4D、Octane、Blender 高级产品渲染、微距商业产品摄影和中国江南水墨美学。采用东方诗意写实场景与精致 Q 版彩塑潮玩的结合方式。画面基调温润、细腻、唯美、治愈。背景为江南古镇水乡：白墙黛瓦、小桥流水、远山烟雾、湖边亭台、乌篷船、竹影、红枫、暖橘色夕阳。以低对比、浅景深、朦胧水墨背景衬托高清晰度 3D 产品主体。
>
> **配色（带 hex）** —— 大量运用米白、暖白、浅杏色、烟灰蓝和柔和暖金色，局部使用朱红、石青、暖橙、墨黑作为产品识别色。主色彩：朱红 #C83227／石青 #355775／暖橙 #E66B35／墨黑 #292522／月白 #F4EDE3／香槟金 #CBA66A。整体保持色调稳定，不要出现霓虹色、过强饱和度、赛博朋克或廉价卡通效果。
>
> **光影和材质** —— 使用暖色自然日光、柔和侧逆光、真实环境反射和高级电影级景深。产品为高精度微缩实体潮玩模型，采用细腻哑光树脂彩塑、手工陶塑质感与精细涂装。脸颊圆润，具有柔和红晕、细腻皮肤质感与自然高光。服饰具有真实布料褶皱和彩绘纹理，部分配饰为金色金属材质。船体为深浅交错的仿木纹雕刻，具有真实木板拼接、金色船头装饰及红色流苏。水盆采用高品质青花瓷，盆内水体清澈透明，具有细腻水纹、真实倒影、波纹折射、环境高光及少量漂浮红枫叶。**必须呈现高级商业产品摄影质感，使产品看起来像已经生产出来、可以真实销售的高端实体文创潮玩。**

四段分别覆盖：渲染管线与基调 → 配色（带数值 + 反崩坏否定）→ 光影 → 逐件材质。最后一句「已经生产出来、可以真实销售」是整套描述的质量闸门。

## Key Takeaways

1. 材质 / 配色 / 字体 / 光影四个槽位必须逐一点名，禁用「高级 / 精致 / 优质」。
2. 主色一律带 hex 或 RGB 数值。
3. 配色分三层：留白底色 → 低饱和情绪色 → 小面积点缀色。
4. 中英文字体刻意拉开风格差，反差本身就是设计语言。
5. 禁止项按三层检查：反套路 / 反廉价 / 反崩坏，一层都不能漏。
6. IP 角色用比例公式（30/70、三头身）+ 冷静脸配夸张动作，不用形容词堆。
7. 用「四词交叉定位」找独特性，用「从 X 逻辑变成 Y 逻辑」说清创新点。
