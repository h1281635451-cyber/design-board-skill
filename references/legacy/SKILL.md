# 设计展板提示词库

把「一套视觉统一的多张设计展板」写成 AI 能稳定执行的提示词。核心不是文采，是**结构锁定**：先用一致性声明和基底参数把跨张不变的东西钉死，再逐张只写差异。

## 何时使用

- 为一个设计项目写 AI 出图提示词：课程作业 3 张、竞赛展板 5 张、VIS 手册 20 页
- 需要多张图**看起来像同一个人做的**（同一 IP、同一配色、同一网格）
- AI 出图翻车需要纠偏：中文字乱码、角色每张长得不一样、五张像五个项目、版面像电商详情页
- 已有参考图，想让 AI「100% 参考这张的排版风格」再换内容

## 六段提示词架构

库里每一套模板都是这六段，顺序不可调换。写新提示词时按此顺序填空：

1. **一致性锁定** — 第一句话就锁死。「请一次性为我生成 N 张…必须属于同一个设计项目、同一套视觉系统、同一套 IP 角色，角色造型、配色、材质、五官、比例在五张中必须高度一致。」
2. **项目设定** — 项目名称 / 副标题 / 核心概念。核心概念要有一句可传播的反差主张（「生肖不是身份，是状态」「它什么都要抱」）。
3. **主视觉系统** — 角色或主体的造型公式、材质、配色、字体、光影。这一段决定「高级感」能否成立。
4. **逐张规格** — 每张一个独立段落：布局词 + 版面占比 + 模块清单 + 该张独有内容。
5. **全局统一要求** — 跨张的网格、留白、对齐、边框、光影一致性声明。
6. **禁止项** — 收尾的负面清单。库里 `不要` 出现 125 次，这是最高频的装置，不是装饰。

## 三档递进（最重要的选择）

同一个设计门类，库里往往存了 2–3 个档位。先选档，再填内容：

| 档 | 特征 | 何时用 |
|---|---|---|
| **基础版**（…描述词） | 内容完整、文字多、模块密 | 课程作业需要信息量和推导过程 |
| **效果版**（字少不容易崩坏） | 图占比 ≥85%，只留标题 + 1–2 字极简标注 | **默认起点**。中文一多就乱码，这是最稳的档 |
| **高级版** | `[统一基底参数]` + 实验性版式词汇 + 占位符驱动 | 竞赛 / 作品集，要 RCA·UAL 那种高级感 |

库里还有刻意成对保留的 **平庸版（理性）** 与 **冲击力强** 两种信息可视化模板——同一主题两种气质，按评审口味挑。

## `[统一基底参数]` 机制

高级版的核心技巧。把跨张不变的视觉参数抽成一段独立文本，之后每张提示词都以 `[统一基底参数]，` 开头，后面**只写这张独有的布局和内容**。基底参数固定包含八项：

尺寸 → 风格参照（如 RCA 实验性叙事排版 + UAL 高级商业质感）→ 底色肌理 → 主色撞色（必须带 RGB 数值）→ 中英文字体反差 → 留白与分割线 → 清晰度（8K 高清无水印）→ 无关文字排除（无作者姓名、指导教师、致谢）

VIS 手册用的是同一机制的变体：`[通用前缀]`，20 页每页开头都复述一次。

## 系列延续句

第 2…N 张**不能只写新内容**，开头必须复述一致性，否则风格会漂：

> 与上一张风格 100% 完全统一，竖版 A3 尺寸，使用完全相同的底色、字体、边框和排版逻辑，延续字少图多的高级作品集质感，所有内容为全新模块，不与第一张重复。

「不与第一张重复」和「风格 100% 统一」必须同时出现——只说统一会得到五张一样的图，只说不重复会得到五个项目。

## 工作流

1. **定门类** → 查上表 → 只读对应的那一个 `references/` 文件
2. **选档** → 默认效果版；要高级感上高级版；要信息量上基础版
3. **整体复制模板**，只替换占位符（`[方括号]`、`（圆括号）`、`（文创名称）`、`[统一基底参数]`）。不要改写结构和禁止项——那些是调通过的
4. **逐张补齐**三件事：布局词、版面占比、模块清单
5. **收尾加禁止项**，至少覆盖：奖项 LOGO、页码编号、水印、乱码、拼版九宫格、作者导师学校信息
6. **出图后按 `cheatsheet.md` 的质量门禁自检**，翻车了查对应的纠偏条目

## 质量门禁

出图后逐条检查，任何一条不过就改提示词重出，不要靠后期修：

1. N 张是否都真的输出了（常见只出第 1 张就停）
2. 中文字是否全部可读、无乱码、无伪文字、无错别字
3. 角色 / LOGO / 主体在五张中造型、配色、比例是否一致
4. 是否出现了奖项 LOGO、页码、水印、作者导师学校信息
5. 是否被拼成一张长图 / 九宫格 / 多张小图并排
6. 图占比是否达标（效果版 ≥85%），留白是否充足
7. 整体像不像同一个设计师做的完整系列
