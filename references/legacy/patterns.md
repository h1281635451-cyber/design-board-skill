# 可复用骨架

六个填空骨架。整体复制，只替换占位符，不改句式与结构。

## 三张课程作业版（效果版，默认起点）

**When to use**: 课程作业 / 作品集，需要稳出图、不崩坏，中文字尽量少。

**How**:
```
展板1：
生成竖版A3尺寸的（高校设计作业 / 竞赛）（门类）展板，100%参考提供的（参考图名称）的排版风格与高级质感，
整体为成熟作品集页面，字少图多，以（核心视觉类型，如3D潮玩渲染）为绝对核心，
文字仅保留核心标题与极简说明，边框整洁，（底色）底色搭配（主色调）点缀，
字体统一为（中文字体）+（英文字体）辅助。
严格采用「顶部通栏大标题 + 中部主视觉群像 + 下方2×2模块化分区」的固定结构，所有元素对齐规整，无多余装饰。
必须包含以下固定模块，内容全部填充对应括号内信息：
1. 顶部通栏
   大标题：（中文名称）（门类）设计
   英文副标题：（英文名称）Design
   右上角小字：（核心文化 / 主题系列）
   左上角极简说明（仅2行）：（一句话设计说明）
2. 中部主视觉（占版面1/3高度）
   居中展示：（主视觉内容）
3. 下方四个等大模块（2×2布局）
   ▢ 模块1：（中文名） | （English Name）
     内容：（图像内容）
   ▢ 模块2：（中文名） | （English Name）
     内容：（图像内容）
   ▢ 模块3：（中文名） | （English Name）
     内容：（图像内容）
   ▢ 模块4：（中文名） | （English Name）
     内容：（图像内容）
```
展板 2、3 换掉中部主视觉定语 + 整套模块清单，开头加系列延续句（见下）。

**Trade-offs**: 最稳、最不容易崩，但信息量低，不适合需要展示推导过程的作业。要信息量就升基础版。

## 系列延续句库

**When to use**: 任何系列的第 2…N 张，开头第一句。缺了它风格必漂。

**How**: 三句按张次递进，「统一」与「不重复」必须同时出现。
```
（第2张）与上一张「（第1张板名）」风格100%完全统一，竖版A3尺寸，使用完全相同的底色、字体、边框和排版逻辑，
延续字少图多的高级作品集质感，所有内容为全新模块，不与第一张重复。

（第3张）与前两张（门类）设计展板风格100%完全统一，竖版A3尺寸，使用完全相同的视觉系统、字体和排版结构，
延续高级作品集质感，全部为（本张主题）内容，形成完整的系列展示。

（五张竞赛版收尾）五张需要像同一个设计团队完成的完整国际竞赛作品。
```

**Trade-offs**: 复述会占提示词长度，但一致性靠字面文本保证比靠模型记忆可靠得多。

## `[统一基底参数]` 填充模板

**When to use**: ≥3 张的系列，或走高级版路线（竞赛 / 作品集要高级感）。

**How**: 先写定义块，再让每张以标记开头。
```
基础信息模板
品牌名：（中文名） | （英文名）
核心定位：（一句话定位）
核心反差：（传统元素特质） × （现代元素特质）

统一基底参数模板（所有展板通用，直接复制到每个提示词开头）
竖版 A3 尺寸，（高校毕业设计展板 / 国际竞赛展板），（风格参照，如 RCA 实验性叙事排版 + UAL 高级商业质感），
（平台 / 赛道锚点，如抖音非遗赛道高流量爆款版式），（基底材质肌理）底色，
主色 1 (RGB: 数值) × 主色 2 (RGB: 数值)（撞色关系，如经典冷暖撞色 / 侘寂风），
（中文字体风格） × （英文字体风格）强烈风格反差，
大留白、（细墨线 / 细银线）轻分割、字少图多、8K 高清无水印，全套风格统一，
无作者姓名、指导教师、致谢等无关文字

展板1：完整 AI 提示词：[统一基底参数]，（布局词），（版面占比），（内容）；（视觉重心），留白充足，无多余文字
展板2：[统一基底参数]，（另一个布局词），……
```
八要素缺一不可：尺寸载体 / 风格参照 / 底色肌理 / 主色带数值 / 中英文字体反差 / 留白分割线 / 清晰度水印 / 无关文字排除。

**Trade-offs**: 前期要花力气写准基底参数，写歪了全套跟着歪；但一旦写对，改一处全套生效。

## 五张竞赛版骨架

**When to use**: 国际竞赛 / 高端作品集，需要完整叙事闭环。

**How**: 六段架构 + 五段视觉节奏。
```
（1 一致性锁定）请一次性为我生成 N 张完整的（A3 / A1）竖版（竞赛）展板，
N 张必须属于同一个设计项目、同一套视觉系统、同一套（IP / 产品）角色，
（造型、配色、材质、五官、比例）在 N 张展板中必须高度一致。
（2 项目设定）项目名称：（中文名）／（英文名）／（英文系列名）
项目核心概念：（一句反差主张）+（三到五行展开）
（3 主视觉系统）整体视觉方向：（词A × 词B × 词C × 词D）
（连续否定 3–5 条，反套路层）／核心气质：（10–14 个可执行气质词）／字体：…／背景色：…
（4 逐张规格）第1张：概念与总览／第2张：角色或系统图谱／第3张：玩法与结构创新／
第4张：包装与品牌落地／第5张：真实生活使用场景 Hero Image
（5 全局统一）视觉节奏从：概念 → 角色 → 产品创新 → 品牌落地 → 真实生活 逐步推进。
N 张需要像同一个设计团队完成的完整国际竞赛作品。
（6 禁止项）见「禁止项三层模板」。
```

**Trade-offs**: 五张一次出，失败成本最高（任何一张崩了整套要重来）。稳的做法是第 5 张单独出整版 Hero Image。

## 禁止项三层模板

**When to use**: 每套提示词的收尾。三层逐条检查，一层都不能漏。

**How**:
```
禁止出现：
（反套路层——题材的默认视觉陈词）
（反廉价层——模型的默认低质输出）
不要学生作业感／不要廉价潮玩风／拒绝廉价电商详情页样式／不要艳丽渐变背景／
不要霓虹色、过强饱和度、赛博朋克或廉价卡通效果／不要塑料材质／不要夸张五官
（反崩坏层——AI 特有失败模式）
不要出现乱码／不要水印／不要出现展板编号（01 02 03）／不要任何奖项 LOGO（Red Dot / iF / IDEA）／
不要拼版、不要九宫格、不要多张小图并排／无作者姓名、指导教师、致谢等无关文字／
不要人物变形、产品重复、结构错误
只生成（N）张（A3）竖版独立展板，不要拼版，不要把多张放在同一张图里。
```
反套路层要按题材现写：做生肖 → 不要龙纹祥云剪纸红金配色；做国风 → 不要祥云纹样书法宫廷元素堆砌。

**Trade-offs**: 清单长了会稀释权重。控制在 12–20 条，把最可能出现的默认套路放最前。

## VIS 手册 20 页骨架

**When to use**: 品牌 VI / VIS 手册，横版 A4，需要 20 页成套。

**How**: 用 `[通用前缀]` 机制，每页一行。
```
通用全局前缀（每页必加，仅需替换括号内容）
横版 A4 尺寸，（风格参照）排版，（底色）肌理底色带极淡的（传统纹样）暗纹半透明叠加，
（主色 1）×（主色 2）极致冷暖撞色，（中文字体）×（英文字体）强烈风格反差，
超大留白、细虚线轻分割、无多余装饰、8K 高清无水印、无作者无导师无学校信息，
（核心品类）文化数字化转译高级质感，（核心肌理效果），高级杂志质感，成熟商业作品集标准

第 N 页：（页名）
[通用前缀]，（排版类型），（主视觉描述）。文字内容：（左上角 / 右下角）极细字号 "（中文）｜（ENGLISH）"，无其他文字
```
20 页顺序：封面 → 目录 → 品牌理念 → LOGO 标准横版 → LOGO 竖版+符号版 → 标准色卡 → 专属字体系统 → 辅助图形系统 → LOGO 组合规范 → LOGO 禁用规范 → 材质实验 → 办公系统 → 文创产品 → 包装系统 → 服饰系统 → 户外导视 → 数字媒体 → 空间门头 → 室内空间 → 封底。
每页文字统一压到「极细字号 + 中英双标题 + 无其他文字」；封面与封底留白 95%。

**Trade-offs**: 20 页一次出必然有页面崩坏，建议分 4 批（每批 5 页）出，每批都重述 `[通用前缀]`。
