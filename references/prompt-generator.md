# Lite 完整提示词生成器

Lite 免费版与完整版本使用相同的输出质量门槛；免费不等于缩短项目设定或省略版式执行。Lite 不包含专有逐字模板，但能用以下通用结构生成专业、自包含的提示词。

## 生成前四层底稿

### Project Bible

记录名称、定位、用户、场景、问题、价值、流程、机制、功能—部件映射、可见形态、操作姿态、状态、CMF、阶段与证据。逐项标记为“已确认事实”“概念假设（待用户确认）”“待补证据”或“禁止推断”。

### Global Visual Bible

记录张数、独立输出、尺寸/画幅、网格、边距、风格、HEX 色值与占比、字体层级、主体形态锚点、视角、材质、光线、图表、密度和跨张连续元素。建议尺寸须标“建议规格，非赛事强制要求”。

### Board Art Direction

逐张记录唯一评审问题、主张、准确短文案、区域比例、阅读动线、图组数量、主体角度、特写、流程/结构/状态图、证据标签、后期覆字区和不得重复的内容。区域比例合计 100%。

### Constraints

分别记录全局禁止、项目专用禁止和赛事条件禁止；赛事 Logo、署名、学校、导师、页码和模板只服从当届官方规则。

## 双档交付

- **完整专业版**：默认首次交付。每张展开全部项目、视觉、布局、文案和约束信息，复制到新对话仍可执行。
- **精简迭代版**：仅在用户明确要求局部修改、且已有完整专业版时使用；写明继承版本、保持项、修改项和禁止变化项。

快速模式允许显式假设和 `[待补：内容]`，但仍输出完整专业版，不得退化为提纲。

纹样、传统图案、非遗纹样或文化图形项目必须先读取 [纹样与文化图形专项](pattern-design.md)。在四层底稿中增加文化来源与权利状态、对象分类、原型特征、最小重复单元、中心/边饰、中心对称/旋转/镜像规则、二方或四方连续对接边界、线宽、色彩层级及折叠/曲面/开孔载体适配；独立文化图形和 IP 不强制连续构成。

## 最终六段结构

### 1. 一致性锁定

写系列张数、当前张、单张输出，以及主体轮廓、部件数量/相对位置、操作方向、CMF、色值、字体、网格、边距、线宽、镜头、光线和连续锚点。

### 2. 项目完整设定

重复项目名、定位、用户、场景、问题、价值、机制、流程、可见形态、状态、阶段及事实/假设/证据边界。单张不依赖聊天上文。

### 3. 主视觉与统一基底

明确用途、物理尺寸、方向、画幅、网格、边距、风格、背景、色彩占比、字体、材质、镜头、光源和阴影。无官方依据时明确“建议规格，非赛事强制要求”。

### 4. 本张详细规格

写评审问题、唯一主张、准确短文案、从上到下的区域与比例、阅读动线、每区图组数量和内容、主体角度、特写、图表/流程/状态、证据标签、覆字区与本张排除内容；区域比例合计 100%。

### 5. 全局统一与独立输出

列出可检查的一致性锚点，只输出当前一张完整页面。不得写“同上”“沿用上一张”或 `[统一基底参数]` 来代替具体参数。

### 6. 分层禁止项与真实性边界

连续写全局禁止、项目专用禁止和赛事条件禁止；不补造研究、测试、工程、医疗、量产或获奖事实。

纹样专项还须禁止单元形态漂移、对称轴错位、旋转角随机、线宽不一、二方端点断裂、四方四边接缝断裂、中心与边饰层级冲突、伪文化来源、伪设计过程、未授权文化图片和把效果图称为实物。

## 两种生成路径

- **A 一步生成展板预览**：适合图像主导、文字较少的概念预览；仍必须给完整六段提示词。
- **B 素材生成 + 人工排版**：含准确中文、数据、尺寸线、署名或官方模板时优先；分别生成主视觉、产品图和结构示意，再在 Figma、PPT 或 Illustrator 排版。

## 输出契约

按顺序交付：采用资料 → 项目简报 → 赛事适配 → 证据状态 → 四层底稿 → 动态规划 → 每张六段完整提示词 → 路径 A/B 与模型限制 → 待核实项。
