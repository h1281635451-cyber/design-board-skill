# 对话、阶段与动态规划

## 先提取已有信息

从用户输入和附件中提取：身份/学历、项目阶段、设计领域、问题和用户、概念机制、已有成果、真实证据、目标赛事、提交载体、张数/尺寸和风格偏好。不要重新询问已知内容。

## 识别项目阶段

| 阶段 | 信号 | 重点 |
|---|---|---|
| A 从零开始 | 没有明确题目 | 探索问题、用户、场景和概念方向 |
| B 已有想法 | 有概念，机制或证据未清楚 | 明确创新点、关键假设和待验证项 |
| C 设计进行中 | 有草图、模型、CAD、原型或界面 | 盘点成果、缺口和证据 |
| D 已完成 | 项目和素材较完整 | 跳过发散，直接策划提交与展示 |

阶段可以修改。用户要求直接出稿时进入快速模式，用 `[待补：内容]` 标出缺口；深入模式逐轮推进。

## 问题优先级

通常每轮只问一个最影响下一步的问题：

1. 信息很少时先问 A–D 阶段。
2. 未选赛事时先确认身份/学历，再依据领域、成熟度和提交形式给 2–3 个国内候选。
3. 已选赛事时先确认会影响资格的届次、组别或赛道。
4. 已上传完整材料时先总结，再问无法从材料判断的关键缺口。
5. 接受“不清楚”“暂时没有”和“跳过”，但明确采用的假设。

## 动态展板计划

先区分单张图片、多张参赛图片、展板组、PDF、作品集页面、视频说明或程序演示。官方允许上传 N 张图片，不代表必须制作 N 张传统展板。

为每张记录：

- 叙事任务与关键结论；
- 设计价值和对应证据；
- 核心视觉、模块、布局和文字预算；
- 与前后张的联系；
- 缺失材料及“示意/假设/待补”替代方案。
- 准确短文案、各区域比例（合计 100%）、图组数量、阅读动线、主体角度和不得重复的内容。

数量由官方要求、用户指定和项目叙事共同决定，不默认五张、A3、竖版或固定图片占比。

若用户未指定且官方规则未限定，可主动给出展示尺寸建议，但必须标为“建议规格，非赛事强制要求”。尺寸建议要在每张最终提示词中完整展开，不能仅存在于前置说明。

## 项目简报与局部重算

可写环境中维护 `project-brief.md`，至少记录阶段、身份、项目、领域、赛事/届次/组别/赛道、证据、素材路径、载体、张数、风格、假设和下一步。

- 改赛事：重核资格、材料、匿名和版式要求。
- 改张数：保留研究与风格，重排叙事。
- 改风格：保留事实与结构，只更新表现层。
- 新增证据：只更新相关主张和展板。

只有实际写入成功后才报告“已保存”。
