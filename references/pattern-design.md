# 纹样设计与文化图形专项

当用户提出纹样设计、传统图案再设计、非遗纹样、文化图形、装饰图案、团花、边饰、二方连续、四方连续或文化辅助图形时读取本文件。先判断设计对象，再选择工作流；不要把所有文化视觉都叫作纹样。

## 一、对象分类

1. **真正的重复纹样**：存在明确的最小重复单元、延展方向和对接边界；可以按规则平铺。
2. **独立文化图形**：完整人物、动物、器物、场景或象征图形是最小识别单位；跨载体复用不等于连续纹样。
3. **IP 角色形象**：以角色轮廓、比例、服饰、五官、道具和表情为识别锚点；不能为了平铺而任意拆散。
4. **品牌辅助图形**：从 Logo、字标或品牌识别语法派生，用于背景、边带、分区和触点；不得取代主标识规范。
5. **产品应用**：前四类图形进入平面、折叠面、曲面、异形轮廓、开孔载体或立体结构后的适配结果，不是新的文化来源。

允许选择一个主类和多个辅助类。分类时回答：最小识别单位是什么、是否要求无缝重复、改变载体后哪些特征必须保留。

## 二、阶段引导

- **A 从零开始**：先问文化主题是否有可核查来源；再确定设计对象和应用目的。没有来源时只给探索方向。
- **B 已有想法**：确认文化原型、计划保留的特征、设计主题、构成方式、系列数量、载体和展板需求；新增规则标为概念假设。
- **C 设计进行中**：盘点来源图、出处、描摹/线稿、单元、组合、成纹、色卡、载体效果和真实过程稿；只补缺失证据。
- **D 已完成**：直接分类成果，核对来源许可、重复衔接、系列一致性、跨载体适配和展板素材；不强迫用户重新设计。

通常每轮只问一个问题，优先顺序为：文化来源与权利状态 → 对象分类 → 图形原型与保留特征 → 构成方式 → 系列数量 → 应用载体 → 展板交付。

## 三、文化来源与转译证据

Project Bible 增加：文化名称、地区/时期、原始载体、资料出处、图片所有者、使用许可、原型局部、可确认特征、作者新增内容和不确定项。

优先展示：

```text
有出处的完整来源 → 标记具体局部 → 真实描摹/简化稿 → 单元定稿 → 构成或应用
```

- 只有真实存档能证明设计过程；不能从完成图相似性倒推镜像、旋转或绘制顺序。
- 综合多个来源时标为“综合再创作”，不要伪称从一件文物直接提取。
- 没有文化依据时使用“概念建议，待来源核实”，不得编造年代、寓意、工艺或地域归属。
- 公开案例、馆藏图片和第三方作品不因出现在项目中自动获得 MIT 或其他再许可权。

## 四、形态与构成规则

### 独立装饰图形

锁定完整外轮廓、正负形、视觉重心、朝向、关键局部、线条粗细和最小识别尺寸。展示原型对照、线稿、彩稿和可选的异形裁切；不强制生成连续纹。

### 中心图形与边饰

分别写中心主体、内框、外围边饰、角部元素、留白和层级。中心图形承担主题识别，边饰负责围合和节奏；禁止边饰压住中心或多个焦点争抢层级。

### 中心对称、旋转与镜像

- 中心对称：写轴数、中心点、成对元素和轴线间距。
- 旋转：写旋转中心、角度、重复次数和径向间距。
- 镜像：写水平/垂直/斜向镜像轴、是否保留朝向特征。
- 没有过程证据时将这些标为“建议构成规则”，不能声称作者已采用。

### 二方连续

写最小重复单元、水平或垂直延展轴、节距、起止边界、相邻单元连接点、上下留白和裁切安全区。至少展示一次“单元框 + 两次以上重复 + 对接线”。

### 四方连续

写单元矩形边界、横纵节距、直排/错列/半落关系、四边接缝、方向性、旋转或镜像规则及裁切安全区。复检左—右、上—下接缝是否连续，不能只展示一块看似满铺的成图。

### 主题系列

同类成果使用可比较的图框、主体比例、命名位置和色彩结构。系列差异应由主题原型、中心主体或配色承担；不要为了“统一”复制完全相同的图。

## 五、色彩与线条系统

记录主色、辅助色、背景色和强调色 HEX/RGB 及面积比例；注明取色来自可核查来源还是当代概念建议。锁定外轮廓线、内部结构线、装饰细线的相对线宽，规定交叉、闭合、尖角、最小间距和小尺寸简化方式。高饱和方案仍须保证标题、线稿和来源注释可读。

## 六、载体适配

- **大平面**：选择完整成纹、满铺或中心主图，标边距、密度和裁切。
- **细长载体**：使用二方连续或纵向带饰，标延展方向和端部处理。
- **折叠/披挂织物**：同时展示平铺图与至少一个使用状态，标中心和边饰可见区。
- **曲面**：给主要可视面、环绕方向、接缝和被遮挡区域，不把平面图直接贴上去。
- **异形小件**：检查最小线宽、白边、孔位、连接件和轮廓识别。
- **开孔或结构载体**：标摄像头、把手、折边、封口和刀线避让区。
- **立体概念**：结构分层只解释组成；没有样机时不得声称已装配或可制造。

应用图旁说明“来源图形/单元—缩放或裁切—具体部位”。效果图不等于实物、打样或授权合作。

## 七、动态展板模块

按素材决定数量，不默认双页或 A3：

- 来源与权利：文化背景、出处、许可、原型位置；
- 转译过程：局部标记、真实线稿、中间稿、保留与新增；
- 图形系统：独立图形、基本单元、中心/边饰、构成语法；
- 连续构成：二方/四方的单元、方向、节距、接缝；
- 系列系统：等规格主纹、线稿、色卡、名称；
- 载体适配：平面、折叠、曲面、异形、开孔的对照；
- 真实性：已确认、概念建议、待补证据和禁止推断。

每张写唯一评审问题、准确短文案、图组数量、区域比例合计 100%、阅读动线和不应重复的内容。

## 八、完整六段提示词字段

1. **一致性锁定**：对象分类、原型锚点、单元轮廓、线宽、中心/边饰、构成规则、色值、系列编号。
2. **项目完整设定**：文化来源与权利状态、主题、真实过程、概念假设、载体、待补证据和禁止推断。
3. **主视觉与统一基底**：物理尺寸、画幅、网格、字体、色彩比例、线稿精度、纹理、信息密度和后期覆字。
4. **本张详细规格**：来源图、局部标记、线稿、最小重复单元、构成示意、色卡、成纹和应用的逐区位置、比例和图组数量。
5. **全局统一与独立输出**：完整重复所有锚点，只输出当前页，不依赖“同上”。
6. **分层禁止项与真实性边界**：全局、项目、文化权利和赛事条件禁止。

## 九、高密度文化实验视觉

适用于文化图形、酸性视觉或实验编辑项目：使用 12/16 栏混合网格、可控叠置、跨栏裁切、强尺度反差、高饱和撞色、线稿层和注释边栏。必须保留清晰标题、稳定阅读入口、可追踪单元、来源注释和大面积呼吸区；禁止随机拼贴、无意义英文、霓虹堆叠、文化符号混搭和用密度掩盖过程缺失。

## 十、专项禁止与复检

- 禁止单元形态漂移、朝向随机、线宽不一、对称轴错位、旋转角不稳定。
- 禁止二方连续端点断裂、四方连续四边接缝断裂、满铺出现明显空洞或重叠。
- 禁止中心与边饰层级混乱、颜色面积失控、小尺寸细节糊成噪点。
- 禁止伪造文化来源、寓意、传统工艺、设计过程、官方合作、实物或测试。
- 禁止复制第三方角色、Logo、独特构图、文案或未授权图片。

复检时必须能回答：这是什么对象类型；来源与权利是否清楚；基本单元在哪里；构成规则能否复现；接缝是否成立；系列锚点是否稳定；载体上发生了什么具体调整；哪些仍是假设。
