# 纹样设计与文化图形专项

当用户提出纹样设计、传统图案再设计、非遗纹样、文化图形、装饰图案、团花、边饰、二方连续、四方连续或文化辅助图形时读取本文件。先判断设计对象，再选择工作流；不要把所有文化视觉都叫作纹样。

## 对象分类

1. **真正的重复纹样**：有最小重复单元、延展方向和对接边界，可以按规则平铺。
2. **独立文化图形**：完整人物、动物、器物、场景或象征图形是最小识别单位；跨载体复用不等于连续纹样。
3. **IP 角色形象**：以角色轮廓、比例、服饰、五官、道具和表情保持识别；不能为平铺任意拆散。
4. **品牌辅助图形**：从 Logo、字标或品牌语法派生，用于背景、边带与触点；不替代主标识规范。
5. **产品应用**：图形进入平面、折叠面、曲面、异形轮廓、开孔载体或立体结构后的适配结果。

项目可设一个主类和多个辅助类。先回答最小识别单位、是否需要无缝重复、载体变化后必须保留什么。

## A–D 阶段引导

- **A 从零开始**：先确认文化主题与可核查来源，再确定对象类型和用途。
- **B 已有想法**：确认图形原型、保留特征、主题、构成方式、系列数量、载体和展板需求；新增规则标为概念假设。
- **C 设计进行中**：盘点来源、出处、线稿、单元、组合、成纹、色卡、应用和真实过程稿。
- **D 已完成**：直接分类成果，核对来源许可、重复衔接、系列一致性和跨载体适配，不要求重新设计。

通常每轮只问一个问题：文化来源与权利状态 → 对象分类 → 原型与保留特征 → 构成方式 → 系列数量 → 应用载体 → 展板交付。

## 文化来源与真实性

记录文化名称、地区/时期、原始载体、资料出处、图片所有者、使用许可、原型局部、可确认特征、作者新增内容和不确定项。优先展示“有出处来源—局部标记—真实中间稿—完成图形”。

- 只有真实存档能证明过程，不能从完成图倒推镜像、旋转或顺序。
- 综合多个来源时标为“综合再创作”。
- 没有依据时写“概念建议，待来源核实”，不得编造年代、寓意、工艺或地域。
- 第三方作品不因被引用而自动获得 MIT 或再许可权。

## 形态与构成

### 独立图形与中心构图

锁定完整轮廓、正负形、重心、朝向、关键局部、线宽和最小识别尺寸。中心构图分别写中心主体、内框、外围边饰、角部元素、留白和层级；禁止边饰压住中心。

### 中心对称、旋转与镜像

中心对称写轴数与中心点；旋转写中心、角度和次数；镜像写水平/垂直/斜向轴及方向性。没有真实过程时标为建议构成规则。

### 二方连续

写最小重复单元、水平或垂直延展轴、节距、起止边界、连接点、上下留白和裁切安全区；展示“单元框 + 两次以上重复 + 对接边界”。

### 四方连续

写单元矩形、横纵节距、直排/错列/半落关系、四边接缝、方向性、旋转或镜像规则和裁切安全区；复检左右、上下是否无缝。

### 主题系列

同类成果统一图框、主体比例、命名和色彩结构，让主题原型、中心主体或配色形成差异，不复制完全相同的图。

## 色彩、线条与视觉层级

记录主/辅/背景/强调色 HEX/RGB 和面积比例，说明取色来自来源还是当代建议。锁定外轮廓、结构线和装饰线的相对线宽，以及闭合、尖角、最小间距和小尺寸简化。高饱和风格仍须保持标题、线稿和来源注释可读。

## 载体适配

- 大平面：标完整成纹、满铺或中心主图的边距、密度和裁切。
- 细长载体：使用二方连续或纵向带饰，标方向和端部。
- 折叠/披挂织物：同时展示平铺和使用状态，标中心与边饰可见区。
- 曲面：说明主要可视面、环绕、接缝和遮挡。
- 异形小件：检查最小线宽、白边、孔位、连接件和轮廓。
- 开孔/结构载体：标摄像头、把手、折边、封口和刀线避让区。
- 立体概念：分层图只说明组成，没有样机时不声称可制造。

效果图不等于实物、打样或授权合作。应用旁标“来源图形/单元—缩放或裁切—具体部位”。

## 展板规划

按素材选择来源与权利、转译过程、图形系统、连续构成、系列比较、载体适配和真实性模块，不默认双页或 A3。每张写唯一评审问题、准确短文案、图组数量、区域比例合计 100%、阅读动线和不重复内容。

## 完整六段提示词字段

1. 一致性锁定：分类、原型、单元、线宽、中心/边饰、构成规则、色值和系列编号。
2. 项目完整设定：来源与权利状态、主题、真实过程、概念假设、载体、待补证据和禁止推断。
3. 主视觉与统一基底：尺寸、画幅、网格、字体、色彩比例、线稿精度、纹理和密度。
4. 本张详细规格：来源图、局部、线稿、最小单元、构成示意、色卡、成纹和应用的逐区比例与图组。
5. 全局统一与独立输出：每张重复完整锚点，不依赖“同上”。
6. 分层禁止项与真实性边界：全局、项目、文化权利和赛事条件禁止。

## 高密度文化实验视觉

使用 12/16 栏混合网格、可控叠置、跨栏裁切、强尺度反差、高饱和撞色、线稿层和注释边栏。保持清晰标题、稳定入口、可追踪单元、来源注释和呼吸区；禁止随机拼贴、无意义英文、霓虹堆叠、文化符号混搭或用密度掩盖过程缺失。

## 专项禁止与复检

禁止单元漂移、方向随机、线宽不一、对称轴错位、旋转角不稳、二方端点断裂、四方四边断裂、中心和边饰争抢、颜色失控、伪文化来源、伪过程、伪实物、无授权 Logo/角色/图片。

复检：对象类型是什么；来源和权利是否清楚；最小单元在哪里；规则能否复现；对接边界是否成立；系列是否稳定；载体具体改变了什么；哪些仍是假设。
