# Design Board Prompts Lite

## v1.1 纹样设计专项

Lite 现已支持纹样设计、传统图案再设计、文化图形和装饰图案项目。它会先区分真正的重复纹样、独立文化图形、IP 角色、品牌辅助图形与载体应用，再按项目阶段询问文化来源、图形原型、主题、构成方式、系列数量、应用载体和展板需求。完整原创案例见 [纹样设计演示](examples/pattern-design-demo.md)。

专项输出继续使用完整六段提示词，包含明确画布尺寸、视觉基底、中心图形与边饰、旋转/镜像/重复规则、最小重复单元、对接边界、逐区比例、载体适配、系列一致性和双层禁止项。来源不足时只提供明确标记的概念建议，不编造文化出处或设计过程。

面向中国高校设计竞赛的免费 Codex Skill：在用户调用后，通过对话理解项目阶段、识别国内赛事方向、梳理真实设计证据、动态规划展板，并编写可修改的图像生成提示词与人工排版说明。Lite 本身不自动生成图片、不自动报名，也不后台获取实时赛事规则。

## 为什么做这个 Skill

设计展板不是把漂亮图片塞进固定模板。不同项目、赛事、组别、赛道和素材状态需要不同的展示逻辑。Lite 先帮助你回答“项目要证明什么”，再决定“做几张、每张说什么、如何生成素材”。

## 适合谁

- 正在准备课程作业、毕业设计、作品集或国内高校设计竞赛的学生；
- 需要帮助学生梳理项目证据和展板叙事的教师、导师；
- 只有早期想法，不知道从问题、用户还是赛事开始的设计者；
- 已有草图、CAD、原型、界面或完整项目，需要重新组织提交材料的团队；
- 希望为 ChatGPT 图像、即梦或 Midjourney 编写结构化提示词，并在 Figma、PPT 或 Illustrator 完成准确排版的用户。

## 调用后的主动引导流程

“主动引导”指 **用户调用 Skill 之后**，Skill 根据已有信息决定下一步，而不是自动弹窗或后台运行：

1. 读取用户已给出的文字、附件和项目简报；
2. 识别 A–D 项目阶段，不重复询问已知信息；
3. 通常每轮只问一个最影响下一步的问题；
4. 基础识别国内赛事简称，并要求确认届次、组别和赛道；
5. 区分真实证据、演示假设和待补材料；
6. 根据载体和内容动态规划展板数量与逐张任务；
7. 输出风格方案、系列设定、逐张提示词和待核实项。

用户可随时选择快速模式、深入模式、跳过问题、换比赛、改张数或只重写某一张。

## 主要能力

- 识别 A 从零开始、B 已有想法、C 设计进行中、D 已完成四个阶段；
- 支持快速模式、深入模式、跳过问题和中途修改；
- 基础识别 NCDA、华灿奖、米兰设计周中国高校作品展、全国大学生数媒竞赛和中国研究生“美丽中国”；
- 根据项目证据动态规划 1 张、2 张、3 张或更多页面；
- 覆盖产品、硬件、医疗、交互、服务、品牌、包装、文化和可持续项目；
- 提供八类可混合风格；
- 生成通用、ChatGPT 图像、即梦和 Midjourney 提示词；
- 明确区分真实证据、概念假设和待补材料。

这些能力由当前仓库中的 `SKILL.md` 和 `references/` 提供。赛事基础识别不是实时规则查询；“生成提示词”也不等于已经调用图像模型生成成品。

## 支持的设计类型

| 类型 | Lite 可协助组织的内容 |
|---|---|
| 工业产品、消费产品、智能硬件 | 场景、功能机制、结构示意、三视图、人机、CMF、制造假设和验证计划 |
| 医疗健康 | 角色、工作流、风险、隐私、误用防护和验证边界，不生成医疗效果结论 |
| 数字交互、UI/UX、交互装置 | 用户目标、任务流程、信息架构、界面状态、原型和测试计划 |
| 服务设计 | 利益相关者、用户旅程、触点、服务蓝图和实施机制 |
| 品牌、VIS、包装、文化创新 | 文化依据、定位、识别逻辑、规范、包装结构和应用场景 |
| 可持续与跨学科 | 系统边界、材料/能源、影响路径、权衡、证据来源和学科分工 |

## Lite 与 Pro 的边界

Lite 保留完整基础工作流，可独立完成项目诊断、基础赛事路由、展板策划和通用提示词输出。

公开版不包含完整逐字模板、旧版模板库、完整商业案例、深度赛事规则库、获奖图像资产或 Pro 专有提示词。Lite 不依赖这些内容即可运行。

## 安装方式

- **Download ZIP**：从 [GitHub 仓库](https://github.com/h1281635451-cyber/design-board-skill) 下载并解压，把文件夹重命名为 `design-board-prompts-lite`，完整复制到 Codex Skills 目录。
- **Git**：执行 `git clone https://github.com/h1281635451-cyber/design-board-skill.git design-board-prompts-lite`。

两种方式都必须保留 `SKILL.md`、`agents/`、`references/` 和 `examples/`。完整步骤、常见路径、更新、排错和卸载见 [新手安装教程](INSTALL.md)。

## 快速开始

1. 按 [新手安装教程](INSTALL.md) 把仓库文件夹放入 Codex Skills 目录，并将文件夹命名为 `design-board-prompts-lite`。
2. 在 Codex 中输入：

```text
使用 $design-board-prompts-lite。我有一个智能硬件想参加国内设计比赛，目前只有草图和 CAD，请先判断阶段并规划 2 张展板。
```

3. 你可以随时说：

```text
快速模式，缺少的内容用待补标记。
改成 3 张，但不要改动已经确认的研究内容。
只把第 2 张改成工程技术理性风格。
```

## 最小示例

输入：

```text
使用 $design-board-prompts-lite。我是本科生，有一个帮助独居老人管理药物的桌面设备概念，想参加国内设计比赛，但还没有测试数据。
```

Skill 应先识别为“已有想法”，明确没有测试数据，再询问最关键的使用问题。它不会虚构调研人数或医疗效果，也不会默认生成五张 A3 展板。

完整流程见 [项目演示](examples/demo-conversation.md)，更多可复制输入见 [示例提示词](examples/example-prompts.md)。

## 本地验证

无需第三方 Python 包：

```powershell
python scripts/validate_lite.py
```

校验器会检查必需文件、相对链接、Skill frontmatter、敏感信息模式、Pro 资源、绝对路径和不应公开的二进制文件。

## 限制

- Lite 不是报名系统，也不会自动获得实时赛事规则；
- 不能替代真实用户研究、工程验证、医疗或法律判断；
- 图像模型可能生成错误文字、结构和细节，正式提交前必须人工复核；
- Skill 不会自动弹窗，也不能保证跨会话保存状态。
