# Design Board Prompts V2

The full V2 replaces Lite as the repository entry point. Install this repository as `design-board-prompts-v2`. See [the main README](README.md) and [SKILL.md](SKILL.md).

V2 defaults to a standalone comprehensive presentation board plus supporting boards, with complete visible text for design review. Text-free assets are delivered on request or after approval for post-production.
