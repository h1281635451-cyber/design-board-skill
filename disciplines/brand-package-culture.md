# 品牌、包装与文化创新

- 典型问题：品牌为谁表达什么价值；文化来源如何转译；载体如何形成一致体验。
- 展示目的：证明定位、识别逻辑、系统性和应用适配。
- 领域关注：文化依据、品牌定位、符号生成、识别规范、包装结构、信息层级与体验传播。
- 必需模块：受众/定位、概念来源、核心识别、规则和关键应用。
- 可选模块：命名、Logo 制图、色彩字体、辅助图形、包装展开、材料工艺、触点和传播。
- 原始素材：文化来源、商标/版权状态、Logo 源文件、包装刀版、样品照片。
- 推荐图形：概念推导、识别系统、比例/安全区、包装结构、应用场景。
- 误区：传统元素堆砌；未经许可复制文物/IP；只做 mockup；包装无结构和法规信息边界。
- 叙事：文化/市场洞察 → 定位 → 符号系统 → 载体规则 → 一致体验。

## 纹样与文化图形分支

命中纹样、传统图案、非遗纹样、文化图形、装饰图案或连续构成时，读取 [纹样与文化图形专项](../references/pattern-design.md)。先判断是真正重复纹样、独立文化图形、IP 角色形象、品牌辅助图形还是产品应用，再选择来源证据、构成与载体模块；不要强制所有项目执行二方或四方连续。
