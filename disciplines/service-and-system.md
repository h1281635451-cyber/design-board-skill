# 服务与系统

- 典型问题：多角色如何协作，触点和后台机制在哪里断裂，方案如何实施。
- 展示目的：呈现端到端体验、组织机制和可落地边界。
- 领域关注：利益相关方、旅程、触点、前后台流程、资源交换、运营和试点证据。
- 必需模块：系统边界、角色、核心旅程、价值交换、服务蓝图。
- 可选模块：生态图、商业/公益机制、治理、实施路线、试点和指标。
- 原始素材：访谈、流程观察、触点、组织规则、试点记录。
- 推荐图形：利益相关者图、旅程、蓝图、系统循环、实施阶段图。
- 误区：只做 App 界面；流程箭头无主体；忽略后台责任；编造合作机构。
- 叙事：系统问题 → 角色冲突 → 新服务机制 → 前后台协作 → 实施与验证。
