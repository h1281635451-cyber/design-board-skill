# 交互与体验

适用：数字交互、UI/UX、交互装置。

- 典型问题：用户目标、关键任务、上下文、信息结构和失败路径。
- 展示目的：说明系统如何工作以及为何比现状更清晰、可用或有意义。
- 领域关注：研究依据、任务路径、信息架构、状态完整性、原型和测试迭代。
- 必需模块：用户目标、主流程、关键状态、系统边界、可用性证据或待验证项。
- 可选模块：旅程、IA、线框、异常/空/加载状态、交互原型、测试任务和版本变化。
- 原始素材：流程、线框、高保真界面、原型链接、测试脚本与记录。
- 推荐图形：任务流、状态机、界面序列、设备场景、交互装置空间关系。
- 误区：堆 UI 截图；只画 Happy Path；用视觉好看替代可用性；虚构测试数据。
- 叙事：任务问题 → 信息/流程 → 关键交互 → 状态系统 → 测试与迭代。
