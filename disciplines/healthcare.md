# 医疗健康

- 典型问题：患者、照护者和医护人员的任务、风险、隐私、依从性与环境约束。
- 展示目的：证明使用价值与风险意识，不把概念设计表述为医疗结论。
- 领域关注：利益相关者、工作流、安全、可清洁性、误用防护、可达性、验证与合规边界。
- 必需模块：场景/角色、任务流程、风险与假设、核心机制、证据等级。
- 可选模块：服务蓝图、人体工学、材料消毒、界面状态、报警逻辑、专家访谈和可用性测试。
- 原始素材：访谈/观察授权、临床或规范来源、原型、风险清单和测试记录。
- 推荐图形：角色旅程、风险矩阵、设备/服务流程、关键交互状态。
- 误区：声称治疗效果；伪造医生背书；使用可识别患者信息；无依据写医疗参数。
- 叙事：健康场景 → 风险/需求 → 方案机制 → 使用与异常 → 验证边界。
