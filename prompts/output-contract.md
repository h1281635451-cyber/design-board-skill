# 输出契约

最终交付按以下顺序，省略不适用项：

1. **采用的资料**：用户材料、赛事档案、领域、风格与来源日期。
2. **项目简报**：问题、对象、机制、阶段和关键假设。
3. **赛事与赛道适配摘要**：正式名称、届次、组别、赛道、资格、核实状态。
4. **官方要求 / 评审关注 / Skill 建议**：三个独立小节。
5. **素材与证据清单**：已有、缺失、可用替代；概念假设显式标记。
6. **动态展板计划**：每张的叙事、主张、证据、核心视觉、模块、布局和联系。
7. **四层生成底稿**：Project Bible、Global Visual Bible、逐张 Board Art Direction 与 Constraints；显式区分事实、概念假设、待补证据和禁止推断。
8. **逐张完整提示词**：默认输出完整专业版，每张严格展开六段，可单独复制，不写“同上”、`[统一基底参数]` 或隐式继承。只有用户明确要求局部修改时才给精简迭代版。
9. **排版与生成建议**：选择路径 A 或 B，说明模型限制。
10. **待核实项与下一步**：只列真正阻塞或影响提交的事项。

快速模式允许占位符，但必须使用 `[待补：具体内容]`，不得伪装成事实。

默认交付遵循 SKILL.md 的“综合主展板与完整带字效果稿”：先交可独立提交的综合主展板，再用分展板展开；写明总数量和实际入画文案。只有明确的素材请求或确认后的后期制作才使用无字版。
