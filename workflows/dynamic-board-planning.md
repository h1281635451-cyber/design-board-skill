# 动态展板与提交材料规划

## 先确定载体

区分：单张参赛图片、多张作品图片、传统展板组、参赛 PDF、作品集页面、视频分镜、软件/程序说明或答辩材料。官方允许 N 张图片不等于必须制作 N 张完整展板。

优先级：官方强制要求 > 用户指定 > 项目证据与叙事需要 > Skill 建议。数量、尺寸、方向、分辨率、署名和模板都必须来自这个顺序。

## 每张规划字段

| 字段 | 内容 |
|---|---|
| 叙事任务 | 这张在整套中的唯一职责 |
| 关键结论 | 评审看完应理解什么 |
| 设计价值 | 新颖性、可用性、技术、文化或社会价值 |
| 证据来源 | 用户素材、官方要求、真实测试或明确假设 |
| 核心视觉 | Hero、场景、流程、爆炸图、界面状态等 |
| 模块 | 从 `content-modules/` 选择，不全量堆叠 |
| 文字预算 | 列出实际入画的标题、模块名、必要说明和图例，默认完整带字 |
| 布局 | 网格、占比、阅读顺序和留白 |
| 连续关系 | 承接上一张、引出下一张，避免重复 |
| 缺失与替代 | 待补证据、示意图或概念假设的显式标签 |

规划完成后，为每张补充 Board Art Direction：准确短文案、区域比例（合计 100%）、各区图组数量、主体角度、局部特写、阅读动线、禁止重复内容和单张输出边界。规划表不能代替最终六段提示词。

## 主张—证据—视觉表达

每个关键主张必须对应证据和表达：

```text
主张：设备适合单手操作
证据：真实尺寸、握持样机照片、任务测试（若有）
视觉：1:1 手部场景 + 尺寸线 + 测试摘要
无证据时：标记“人体工学概念假设，待样机验证”
```

禁止把概念渲染称为样机，把推测称为调研结论，把虚构结构称为工程方案。

## 尺寸建议的标注

只有官方规则或用户确认的尺寸可直接作为提交规格。为概念展示主动建议 A3、A2 或屏幕画幅时，必须紧邻写明“建议规格，非赛事强制要求”，并在最终每张提示词中展开毫米尺寸与画幅，不得只在系列说明出现一次。

## 数量建议

自动建议时给范围和理由，不套固定五张：单张适合一个明确结论；2–3 张适合概念—机制—场景；4–6 张适合证据丰富的系统项目；更多页面适合 PDF/VIS/作品集。若官方只收有限图片，优先合并信息而非伪造更多板。


默认交付遵循 SKILL.md 的“综合主展板与完整带字效果稿”：先交可独立提交的综合主展板，再用分展板展开；写明总数量和实际入画文案。只有明确的素材请求或确认后的后期制作才使用无字版。
