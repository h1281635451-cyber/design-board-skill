# 参考图与获奖案例分析

## 先登记身份

记录作者、作品、赛事、届次、赛道、来源 URL、访问日期、许可/用途和证据类型：

- `official-showcase`：官方获奖展示图，不保证是原始参赛版式；
- `original-submission`：有可靠来源证明的原始提交；
- `style-inspiration`：普通视觉参考；
- `unverified`：身份不明，不得标称获奖作品。

## 只提取可迁移规律

分析版心、列网格、边距、留白、图片占比、色彩关系、字体层级、信息密度、阅读路径、图表语言、摄影/渲染和跨页节奏。将结果写成数值或关系规则，例如“12 栏，主图跨 8 栏；暖白底，深灰正文，橙色强调不超过 8%”。

不要逐像素复制布局，不复刻 Logo、受保护插画、专有角色、独特文案或可识别品牌资产。来源或许可不明的图片不打包进公开 Skill。
