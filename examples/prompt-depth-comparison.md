# Dose Dock 修复前后对照

本对照评估提示词的执行信息，不声称已生成图片。

| 检查项 | 修复前 | 修复后 |
|---|---|---|
| 产品定义 | 第 2 张依赖前文，形态约束较少 | 两张均完整重复用户、场景、目标、机制、轮廓、部件位置和证据状态 |
| 展板尺寸 | 只有“竖版”和视觉边距 | 每张明确 A3 297 × 420 mm、画幅、安全边距，并标为非赛事强制要求 |
| 风格与材质 | 工程理性、暖灰、哑光塑料较概括 | 增加色彩占比、字体层级、具体材质、镜头、光源和阴影 |
| 具体内容与文案 | 只有模块主题 | 每区有准确短文案、图组数量、角度、证据标签和排除内容 |
| 区域比例 | 大区比例粗略，位置与标题区含混 | 10/44/18/28 与 10/44/20/26，区域比例合计 100%，阅读动线明确 |
| 全局约束 | 通用禁止为主，使用隐式继承 | 两张展开一致性锚点、独立输出、全局禁止、项目专用禁止和赛事条件禁止 |

结论：改善来自项目、视觉、逐张导演和约束信息的闭合，而不是单纯把提示词变长。完整提示词见 [Dose Dock 两张成品](dose-dock-full-prompts.md)。
