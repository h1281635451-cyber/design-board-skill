# Lite 示例输入与提示词

以下内容均为公开版原创示例。它们展示方法，不是固定模板或赛事规则。

需要查看从用户输入、阶段引导、动态规划到三张最终提示词的单文件案例，请阅读 [Warm Harbor 暖湾防烫托盘](warm-harbor-complete-demo.md)。该案例是明确标注假设的原创适老工业产品演示。

## 示例一：产品项目起步

用户输入：

```text
使用 $design-board-prompts-lite。
我是本科生，正在做一款夜间骑行智能尾灯，已有草图和外观 CAD，没有样机。请判断项目阶段，推荐需要核对的国内赛事方向，并用快速模式规划 2 张展板。所有未验证内容必须标明。
```

期望行为：识别阶段 C；区分 CAD 与样机；先核对工业产品或交互类别；两张分别承担“场景与机制”“结构、交互与验证计划”。

## 示例二：UX 项目深入模式

用户输入：

```text
使用 $design-board-prompts-lite，用深入模式帮助我的校园无障碍导航 UX 项目。已有用户旅程、信息架构和高保真界面，但没有可用性测试。每轮只问一个问题，不要默认做五张。
```

可用于第 1 张的六段提示词示例：

```text
【项目与证据】校园无障碍导航 UX 项目，已有用户旅程、信息架构和界面；没有可用性测试，不生成测试结果。
【系列一致性】白底、深蓝灰正文、青蓝强调，8 栏网格，统一圆角界面卡片和路径图例。
【视觉风格】研究证据导向，优先可读性、来源和状态关系。
【当前页面】解释行动不便用户从确定目的地到选择无障碍路径的任务问题；用旅程和关键阻碍支持设计原则。
【画面执行】左侧旅程，中央路径决策，右侧设计原则；界面截图只作为证据，不做无意义堆叠。
【真实性约束】不生成虚构引语、参与人数、成功率或学校背书；测试区标“待验证”。
```

## 示例三：文化创新与参考图

用户输入：

```text
使用 $design-board-prompts-lite。我要做地方饮食文化包装，上传的参考图只用于分析网格、留白和色彩关系。不要复制图中的品牌、插画或专有构图。先检查我是否有可靠文化来源，再给文化转译实验风格方案。
```

期望行为：要求来源、许可和文化依据；提取一般视觉规律；建立“来源—提取—重构—应用”叙事；避免万能国潮元素。

## 示例四：局部修改

用户输入：

```text
读取项目目录中的 project-brief.md。保持比赛、项目事实和前两张不变，只把第 3 张改成沉浸体验叙事，并重写第 3 张完整提示词。写入成功后再告诉我已保存。
```

期望行为：局部重算，不丢失来源，不假装保存，不用“同上”代替完整提示词。

## 示例五：高文字精度页面

用户输入：

```text
这张页面包含准确中文、尺寸线和数据图表。不要直接让图像模型生成整张成品；请分别给主视觉、结构示意的生成提示词，再给 Figma 可执行的网格、字号、文字和图表排版说明。
```

期望行为：选择“素材生成 + 人工排版”，保留准确数据来源和正式提交要求。
